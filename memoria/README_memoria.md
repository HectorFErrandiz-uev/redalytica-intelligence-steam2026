# /memoria

Memoria académica final del proyecto Redalytica Intelligence.

## Contenido

| Archivo | Descripción |
|---|---|
| `Memoria_Redalytica_Intelligence.pdf` | Memoria académica de 43 páginas, formato A4, en español castellano. Versión PDF final entregada para evaluación. |

## Estructura del documento

| Capítulo | Contenido |
|---|---|
| Portada y resumen ejecutivo | Identificación del equipo, tutor, fecha de defensa y síntesis del proyecto en una página |
| Índice | Navegación completa por capítulos y figuras |
| Capítulo 1. Contexto y motivación | El apagón del 28 de abril de 2025 como detonante. Diagnóstico del sistema eléctrico español |
| Capítulo 2. Objetivos y alcance | Hipótesis de partida, objetivos específicos y delimitación temporal del estudio |
| Capítulo 3. Metodología y arquitectura técnica | Fuentes oficiales utilizadas (REE, OMIE, CNMC), arquitectura del pipeline, validación cruzada |
| Capítulo 4. Análisis del sistema eléctrico peninsular | Generación, demanda, mix tecnológico y emisiones 2020–2026 |
| Capítulo 5. Análisis forense del apagón | Reconstrucción minuto a minuto del 28 de abril de 2025 |
| Capítulo 6. Hallazgos analíticos | Cifras clave: volatilidad, intensidad de carbono, factor de carga, saldo internacional |
| Capítulo 7. Modelo de negocio | Spinoff comercial Redalytica Intelligence: TAM/SAM/SOM, líneas de producto, buyer personas, pricing y proyecciones |
| Capítulo 8. Conclusiones | Síntesis y próximos pasos |
| Bibliografía | Fuentes oficiales y referencias consultadas |
| Anexos | Anexo metodológico DAX y anexo de validación |

## Figuras incluidas

La memoria incluye diez figuras numeradas. Las primeras nueve son capturas del dashboard Power BI; la décima es el diagrama de arquitectura técnica disponible en `/docs/arquitectura_tecnica.png`.
